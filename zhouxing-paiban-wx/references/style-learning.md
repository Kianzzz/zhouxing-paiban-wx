# 排版风格学习

## 目标

学习的是可复用的视觉系统，不是某一篇文章的正文、图片或品牌资产。最终主题应能稳定覆盖另一篇结构不同的公众号文章。

## 证据顺序

1. 实际页面 DOM 与计算样式：可确认选择器、具体数值和层级。
2. 高分辨率长截图：可确认视觉关系，数值只能估算。
3. 局部截图：只能确认出现区域，不能推断全套系统。
4. 用户口述：作为偏好要求，不当作参考页面事实。

## 分析清单

按顺序记录：

- 画布：内容宽度、左右留白、白底/暗底、移动端密度。
- 层级：H1/H2/H3 的相对大小、字重、对齐和前后间距。
- 正文：字号、行高、字色、段间距、两端对齐与否。
- 强调：strong、em、链接的颜色、底纹、描边或字重。
- 模块：引用、列表、代码、表格、图片、分隔线、卡片。
- 色彩：主色、深色、浅色、淡底、边框、中性色；判断哪些属于同一色族。
- 兼容：哪些效果依赖伪元素、外部字体、背景图、脚本或响应式规则。

## 证据卡模板

```markdown
风格名：
来源：图片 / 链接
适用内容：

已观察：
-

推断：
-

未核实：
-

最可能失真：
-

置信度：high / medium / low
```

## 停止条件

- 参考材料不足以看到标题、正文和至少一种强调方式时，不宣称已学会完整风格。
- 颜色或间距存在多个合理解释时，先做一个关键样例让用户确认。
- 证据卡交付后必须先让用户确认研究方向；确认前只允许在临时目录制作候选主题。
- 候选主题通过结构校验和样例预览、并获得用户视觉确认后，才能写入正式风格库。
- 正式入库不等于适合整篇文章；应用到长文前再确认一次关键页面。
