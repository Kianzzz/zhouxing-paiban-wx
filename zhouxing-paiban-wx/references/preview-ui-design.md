# 临时预览页 UI 规范

这份规范只控制排版工具外壳，不控制文章主题本身，也不得进入复制结果。

预览网站外壳采用浅色编辑部网格、大留白、黑白胶囊控件和大圆角内容画布。左上角以大号点阵印刷感英文 `ZHOUXING PAIBAN WX` 为主标题，中文 `周行 · 公众号排版` 作为小号说明；右上角先显示操作提示，再用更弱一级文字显示 `更多 AI 实践玩法 · 公众号「周行今天AI了吗」`，这些都属于工具外壳，不得进入复制结果。右侧设置栏使用完整的半透明白色大圆角矩形承载全部设置，内部两个设置模块也保持白色，仅以浅边线分层，不使用大面积灰色底。设置模块的封面卡保持约 5.5:1 的扁平横向胶囊比例：左侧约三分之一是固定白色信息区，按“模块名 / 数量”纵向排列，右侧才逐步渗入 WebGL 材质，较大的黑色圆形编号轻压右上边缘；模块英文分类放在胶囊上方，不把文字直接压在满版彩色背景上。材质使用域扭曲噪声模拟水墨、烟雾和流沙，保留大块浅色断裂区，不使用多个圆形渐变拼成圆润色块。页面底层环境流光和两个设置模块的流光色板必须跟随当前主题主色及手动主色调整。绿白、墨蓝、沙金和雾紫使用三种高明度、高饱和度的近邻色组成主色族：绿白为薄荷绿、亮翠绿与青绿，墨蓝为天青、亮蓝与蓝紫，沙金为柠檬黄、亮金与珊瑚橙，雾紫为浅紫、亮紫与洋红；不从这些主题的主色生成棕、褐、灰蓝等暗层色，并另配少量色相差异明显的紫蓝、玫红或珊瑚红辅色。石墨档案是黑白灰例外：以主题主色 `#4B5563` 为主要颜料，只搭配浅银灰、深石墨和少量中灰，不使用彩色辅色。用户手动更换主题色后，主色族由新主色向两侧偏移生成三种明亮近邻色，不生成深色档，再生成高差异辅色。主色族约占可见颜料区的 65%–70%，辅色约占 20%，其余由白色断层形成呼吸感。辅色随同一流场进入元素中部和两侧，不被锁死在边缘，但不得重复铺设或压过主色；白色断层继续穿插其中，避免均匀铺满或混成连续双色渐变。除石墨档案外，中性黑白只用于文字、边框和编号，不进入彩色流光。流光应让文章与工具外壳形成统一而不单调的气质，但白色文章纸张和侧栏仍需遮住主体区域，使颜色主要从页面边缘、间隙和胶囊材质区透出。WebGL 不可用时，主辅色 CSS 变量提供静态渐变；系统开启“减少动态效果”时材质保持静止。形状层级保持明确：展示封面、分类切换和动作按钮使用胶囊；下拉控件使用自定义白色圆角菜单，当前选项在菜单内显示为深色胶囊，关闭状态仍保持平面底线、打开后变为浅色胶囊；文字输入保持相同的平面与聚焦逻辑，主题色使用独立圆形色样。外壳的结构、黑白控件与动画强度不随文章主题变化，只有流光主辅色板联动主题主色，且任何外壳样式都不得进入复制结果。

验收时优先检查信息层级、尺寸、间距、留白和流动物料的分布，再检查颜色；不能只凭配色相近判定复刻成功。

动作区分两行：第一行并排“保存为新风格”与“恢复当前风格”，两者使用相同的白色次要胶囊样式；第二行是黑色通栏主按钮“复制排版”。点击保存后用白色大圆角对话卡命名，对话卡必须明示“保存设置、不保存文章内容、只保存在当前浏览器”。保存成功后，新项以“自定义 · 名称”出现在原排版风格下拉菜单，不再创建第三个设置模块。
