# 微信排版兼容边界

## 三层验收

1. **本地预览**：浏览器能显示 CSS，能力最强。
2. **剪贴板 HTML**：复制时将计算样式写入元素的 `style`，会舍弃脚本和工具栏。
3. **微信编辑器**：平台可能继续清理属性、重传图片或改写标签，必须实际粘贴确认。

任一层通过都不能替代下一层。

## 稳定能力

优先使用：字号、字重、行高、颜色、背景色、内外边距、边框、圆角、文本对齐、简单阴影、图片宽度、简单线性渐变。

## 字体

- 公众号正文只保存 `font-family` 声明，不会随文章携带字体文件。读者设备没有该字体时会按字体栈回退。
- 首选系统无衬线栈：`-apple-system`、苹方、微软雅黑、Arial、`sans-serif`。
- 苹方主要存在于苹果平台，微软雅黑主要存在于 Windows；Android 通常使用设备系统中文字体。
- 宋体/衬线和楷体可用于风格表达，但不同设备的字形、字面大小和粗细更容易变化。
- 不使用 `@font-face`、在线字体或本地私有字体名称冒充跨端兼容。

## 图片形式

图片形式是预览页对全部正文图片的覆盖层，不改动原图片文件：直角、圆角、阴影、圆角阴影、描边、圆角描边。选择“跟随主题”时恢复主题原始图片规则。

## 组件与间距覆盖

- H1、H2、H3、引用、代码块、行内代码、加粗、斜体、列表、表格、分隔线和链接的局部样式只覆盖对应语义元素，不改变文章内容或标题层级。
- 组件颜色从当前主题主色推导浅色、深色和阴影色，换主色时一起联动。
- 间距控制只写入段落下间距、H2/H3 上间距、H1–H3 下间距和图片上下间距；不使用负边距或依赖容器定位。
- 切换到内置主题时清空局部组件、字号字重和间距覆盖，防止不同主题规则叠加；切换到浏览器自定义风格时恢复该风格保存的全部覆盖。“恢复当前风格”按当前下拉选项重载，不把自定义风格错误恢复成它的基础主题。

## 浏览器自定义风格

预览页可将基础主题、主色、字体、字号/字重、组件样式和间距覆盖存入当前浏览器的 `localStorage`。不存储文章 HTML、正文、标题、图片数据或链接，也不将它们写入剪贴板之外的任何外部系统。

`localStorage` 按浏览器和页面来源隔离：线上预览页在同一 HTTPS 域名下可稳定复用；本地 `file://` 页面的行为由浏览器决定，因此默认构建使用固定的临时文件路径来降低丢失概率。清除站点数据、更换浏览器、设备或页面来源都可能使自定义风格不可见。该功能不等于将风格写入 Skill 的 JSON 风格库。

## 脆弱能力

- 外部字体、`@import`、动画、hover、fixed/sticky、复杂 grid、复杂伪元素、CSS counter、媒体查询。
- 本地图片 URL、需要登录或防盗链的远程图片。
- 浏览器页面的按钮和 JavaScript；它们只服务预览，不会复制进正文。

## 复制策略

页面优先写入同时包含 `text/html` 与 `text/plain` 的剪贴板；本地文件页面若无现代剪贴板权限，则选中排版容器并调用浏览器富文本复制。成功状态只证明浏览器接受了复制操作。

复制内容会移除编辑属性、ID、预览 class、data 属性和工具栏，只保留文章结构、必要属性与内联样式。不会把桌面预览计算出的固定宽高、最大高度或 overflow 写入普通正文节点；图片改用 `max-width:100%;height:auto`，表格使用流式宽度。链接和图片 `src` 会保留，脚本不会进入复制内容。

章节编号、英文眉题和物化后的伪元素属于视觉装饰，HTML 中使用 `aria-hidden` 标记，生成纯文本剪贴板时删除。有序与无序列表的 marker 会转为带 `aria-hidden` 的内联标记。为避免公众号重写 `ol / ul / li`，复制结果把列表转换为普通 `section + p` 行；每行使用一个 `inline-block` 符号和一个 `inline` 正文容器，不再向公众号传递语义列表标签。原生有序编号使用内容的自然宽度，不统一预留固定编号栏；编号与正文只保留短间隔。纯文本剪贴板仍保留一份编号或符号。

表格使用语义化 `table`、`tr`、`th`、`td`，并在复制结果中保留 `width:100%`、`table-layout:fixed`、统一的 `box-sizing`、垂直对齐和换行规则。每行单元格数量必须一致；这只能降低错位概率，仍需在公众号编辑器实际粘贴确认。
